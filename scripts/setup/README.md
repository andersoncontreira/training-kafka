# Setup Scripts

Helper scripts for setting up the local Kafka environment.

## Scripts

| Script | Description |
|--------|-------------|
| `env.sh` | Sets up environment variables (source this file) |

## Usage

```bash
# Install Kafka locally (script lives under scripts/kafka/)
bash scripts/kafka/install-kafka.sh

# Load Kafka env vars into your current shell
source scripts/setup/env.sh
```
